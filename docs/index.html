Personal Hermes Agent Skills

A curated collection of reusable skills for Hermes Agent — covering systematic review automation, productivity utilities, and Slack tooling. Each skill is self-contained with its own SKILL.md and setup instructions.

Quick Setup

1
Clone or fork this repo, then symlink (or copy) any skill folder into ~/.hermes/skills/
2
Merge .hermes-config/config-patch.yaml into ~/.hermes/config.yaml for auto-approvals needed by CDP browser skills
3
For skills with a SETUP.md, follow the per-skill setup steps (env vars, browser profiles, criteria files)
4
Hermes auto-discovers skills in ~/.hermes/skills/ — just start a new session and the skill will be available

Systematic Review (Covidence) 3 skills
covidence-screening v1.0.0
SKILL.md source

Autonomously screens Covidence references at the title & abstract stage. Votes Yes / Maybe / No against your PICO criteria via CDP-attached browser. Runs unattended after an optional onboarding phase; writes one-line rationale for Maybe votes.

covidence systematic-review title-abstract cdp browser-automation
covidence-full-text-retrieval v1.2.0
SKILL.md source

For each reference in Covidence's full-text review queue, locates an open-access PDF via Unpaywall → Semantic Scholar → arXiv (with optional NotebookLM Discover as last resort) and uploads it via Covidence's "Upload full text" link field. Never casts Include / Exclude — that decision stays manual.

covidence full-text open-access unpaywall notebooklm browser-automation
covidence-full-text-review v1.0.0
SKILL.md source

Two modes: unattended — processes the full-text review queue and casts Include / Exclude votes autonomously; secondary_reviewer — accepts a URL, reads the paper, returns a structured verdict, and optionally casts the vote when a Covidence ref_id is supplied. Verdict delivered via pbcopy for clean paste into Word.

full-text review include-exclude cdp pbcopy

Productivity 1 skill
pbcopy-word-delivery v1.0.0
SKILL.md source

Delivers structured text (verdicts, reports, summaries) directly to the macOS clipboard via pbcopy so the user can Cmd+V into Word without Warp terminal soft-wrap artifacts corrupting line breaks. Uses the heredoc pattern for safe handling of single-quoted content. macOS only (Linux equivalent: xclip).

clipboard macos pbcopy word warp

slack-scan v1.0.0
SKILL.md source

On-demand Slack summary: ask Hermes to summarize today's activity across every channel and DM the bot is in, or target a single named channel. No cron job required. Calls the Slack Web API via curl + SLACK_BOT_TOKEN.
